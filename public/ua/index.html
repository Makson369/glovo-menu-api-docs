Glovo Menu Tool API 1.0.0

API для керування меню закладу в Glovo через menu-tool: товари, опції, колекції, суперколекції, графік роботи та замовлення. Усі оновлення меню відправляються в Glovo асинхронно, тож результат перевіряється окремим запитом за ID транзакції.

Ендпоінти востаннє оновлювалися приблизно 3 роки тому (остання зміна специфікації: 28 жовтня 2023). Документацію взято з github.com/AlterEGO-digital/swagger, тож у робочому API можуть бути відмінності.
Базова адреса
https://menu-tool.glovoapp.com/partners/api

В оригінальній специфікації вказано /partners-api/api, але робочою є адреса /partners/api.

Ідентифікатор закладу

storeAddressId — ID адреси закладу в menu-tool, наприклад choiceqr_123456. Він є в шляху кожного запиту.

Сервер

https://menu-tool.glovoapp.com/partners/api

Автентифікація

Кожен запит містить токен партнера в заголовку Authorization у форматі Bearer (JWT).

ЗаголовокЗначення
AuthorizationBearer <token>
Content-Typeapplication/json
Acceptapplication/json
Security Scheme Type: HTTP  ·  Scheme: bearer  ·  Bearer format: JWT

Заголовки

Authorization: Bearer $TOKEN
Content-Type: application/json
Accept: application/json

Асинхронне оновлення

Зміни меню не застосовуються в Glovo миттєво. Типовий сценарій:

  1. Відправте зміни. PATCH /products/{storeAddressId}/bulk поверне transaction_id.
  2. Зачекайте кілька секунд, поки Glovo обробляє зміни.
  3. Перевірте статус. GET /products/{storeAddressId}/transactions/{transactionId} або GET /products/{storeAddressId}/bulk/{transactionId}. Поки статус PROCESSING, повторюйте запит.
Статуси Glovo
СтатусЗначення
SUCCESSУсі зміни застосовано
PROCESSINGЩе обробляється, перевірте пізніше
PARTIALLY_PROCESSEDЧастину змін застосовано, подробиці в details
NOT_PROCESSEDЗміни не застосовано
GLOVO_ERRORПомилка на боці Glovo
Структура меню
Суперколекції›Колекції›Групи товарів›Товари›Групи опцій›Опції

Приклад details при частковій обробці

{
  "status": "PARTIALLY_PROCESSED",
  "details": [
    "Products updated: [11111, 22222]",
    "Products not updated: [12345, 56789]"
  ]
}

update status of the Order

Allows the update of the order status during different stages of the preparation.

"ACCEPTED": The order has been accepted by the store. Be aware that if you don't accept the order we will still move forward with the order, as we don't require an acceptance to proceed.

"READY_FOR_PICKUP": The order is ready to be picked up by a courier or the customer (Only available for orders delivered by Glovo couriers)

"PICKED_UP_BY_CUSTOMER": The order has been picked up by the customer (Only available for stores with Pickup by customer configuration enabled)

"OUT_FOR_DELIVERY": The courier has collected the order in the store and is now being delivered to the customer (Only available for Marketplace orders)
