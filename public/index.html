Glovo Menu Tool API 1.0.0

API for managing a store's Glovo menu through menu-tool: products, options, collections, super collections, schedule and orders. Menu updates are sent to Glovo asynchronously, so the result is checked with a separate request by transaction ID.

Base URL
https://menu-tool.glovoapp.com/partners/api

The original spec lists /partners-api/api, but the working path is /partners/api.

Store identifier

storeAddressId is the store address ID in menu-tool, e.g. choiceqr_123456. It appears in the path of every request.

Server

https://menu-tool.glovoapp.com/partners/api

Authentication

Every request carries the partner token in the Authorization header as a Bearer token (JWT).

HeaderValue
AuthorizationBearer <token>
Content-Typeapplication/json
Acceptapplication/json
Security Scheme Type: HTTP  ·  Scheme: bearer  ·  Bearer format: JWT

Headers

Authorization: Bearer $TOKEN
Content-Type: application/json
Accept: application/json

Asynchronous updates

Menu changes are not applied in Glovo instantly. The typical flow:

  1. Send the changes. PATCH /products/{storeAddressId}/bulk returns a transaction_id.
  2. Wait a few seconds while Glovo processes the changes.
  3. Check the status. GET /products/{storeAddressId}/transactions/{transactionId} or GET /products/{storeAddressId}/bulk/{transactionId}. While the status is PROCESSING, repeat the request.
Glovo statuses
StatusMeaning
SUCCESSAll changes applied
PROCESSINGStill processing, check again later
PARTIALLY_PROCESSEDSome changes applied, see details
NOT_PROCESSEDChanges not applied
GLOVO_ERRORError on the Glovo side
Menu structure
Super collections›Collections›Product groups›Products›Option groups›Options

Example details on partial processing

{
  "status": "PARTIALLY_PROCESSED",
  "details": [
    "Products updated: [11111, 22222]",
    "Products not updated: [12345, 56789]"
  ]
}

Orders

Update order status

Allows the update of the order status during different stages of the preparation.

"ACCEPTED": The order has been accepted by the store. Be aware that if you don't accept the order we will still move forward with the order, as we don't require an acceptance to proceed.

"READY_FOR_PICKUP": The order is ready to be picked up by a courier or the customer (Only available for orders delivered by Glovo couriers)

"PICKED_UP_BY_CUSTOMER": The order has been picked up by the customer (Only available for stores with Pickup by customer configuration enabled)

"OUT_FOR_DELIVERY": The courier has collected the order in the store and is now being delivered to the customer (Only available for Marketplace orders)
