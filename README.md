# Glovo Menu Tool API — docs

Документація (UA `/`, EN `/en/`) і Postman-колекція (`/Glovo_Menu_Tool_API.postman_collection.json`).

## Локально
```bash
npm start   # http://localhost:3000
```

## Railway
Через GitHub: завантажте цю папку в репозиторій → Railway → New Project → Deploy from GitHub repo.
Або через CLI:
```bash
npm i -g @railway/cli
railway login
railway init
railway up
railway domain   # створює публічну адресу *.up.railway.app
```
